# 迷你猫娘风格Ⅰ

有颜色的光，能走进去的地方。

人设先读 [mini-beast-girl](../mini-beast-girl/SKILL.md)。旧名「色彩」指向这里。默认出图走这套。

**命根子：光是有颜色的，颜色会互相染。** 暖主光对冷阴影。背景是能走进去的地方，不是色场。

衣服、发型、瞳色、表情每次另抽。连体衣 / 开衫 / 兽耳兜帽 / 鞋 / 棉花头的另抽见 [衣柜](../mini-catgirl-wardrobe/SKILL.md)：零件独立参考图，出图时随机组合。身子是人。耳只长头顶。两侧不要人耳。静帧要抖动线条、残影、飞出物时走 [动感](../mini-catgirl-motion/SKILL.md)。

## 这套是什么

和风格Ⅱ的差别是光：这里环境色会染脸；风格Ⅱ是橱窗平光。和风格Ⅲ的差别是地：这里是能走进去的街和屋，不是马卡龙色场。和厚涂的差别是线：这里还有浅浅轮廓。

| 钉什么 | 怎么认 | 不要学成 |
| --- | --- | --- |
| 光 | 暖主光，冷阴影，会染皮肤和衣服 | 高调平光；夜雨喷枪没线 |
| 地 | 能走进去的街、屋、店 | 纯色墙；糖果星星底 |
| 皮 | 浅浅有色轮廓，喷枪过渡 | 粗黑贴纸；油画厚涂 |
| 身 | 迷你人身，头偏大 | 7 头身；人脸安在猫身上 |

## 定稿：端箱

[examples/example-box-held-v1.png](examples/example-box-held-v1.png)

调用名 **端箱**。已点头。出这套就锁这张。不要重出这张肖像。钉的是箱子和人的尺度，不是这张脸。

| 钉什么 | 怎么认 | 不要学成 |
| --- | --- | --- |
| 镜头 | 第一人称往箱里看，约 45°。两只成人手从画面下方托住近角 | 第三人称整箱放地上；看见成人脸或上半身 |
| 箱 | 双手能端的快递箱。箱底铺一块叠好的白毛巾当窝 | 搬家箱；她怀里抱的玩具箱 |
| 人 | 坐在毛巾上，整只在沿口以下。头、耳、毛衣都不探出沿 | 坐箱/探箱那种头出手搭沿、把箱子坐满 |
| 尺子 | 约 20cm。整只 ≈ 一只成人手长。头 ≈ 一只拳头 | 成人手和她脑袋一样大；她把开口撑满 |
| 表情 | 睁眼 wow 看你 | 没点名不要改成睡着或哭 |

换角色：定稿占一张锁尺度，另一张给她自己的定稿。箱子、托法、沿口以下不要改。衣服头发跟那只猫娘。

坐箱、探箱仍锁 v1 / v2。那两张头可以在沿上。端箱、倒箱不要拿它们当尺子。

## 定稿：倒箱

[examples/example-box-fallen-v1.png](examples/example-box-fallen-v1.png)

调用名 **倒箱**。已点头。出这套就锁这张。不要重出这张肖像。钉的是床上开箱、哭脸、和端箱同一把尺子。

| 钉什么 | 怎么认 | 不要学成 |
| --- | --- | --- |
| 镜头 | 略俯往箱里看。箱子放在成人床上。一只右手从右上掀后舌 | 双手托着走在街上；看见成人脸 |
| 箱 | 和端箱同一只快递箱。毛巾窝，前面空一截 | 搬家箱；她把开口撑满 |
| 人 | 坐在毛巾后部，整只在沿口以下。头约占开口 1/3。头发不贴侧壁 | 为了哭脸特写把人放大；坐箱/探箱那种探头 |
| 尺子 | 跟人相对箱子的大小必须跟端箱一致 | 头贴箱壁；成人手和她脑袋一样大 |
| 表情 | 委屈害怕哭哭：眉心挤，眼泪，小哭嘴，短手攥胸口 | 端箱那种 wow；大笑 |

换角色：定稿占一张锁尺度和哭脸，另一张给她自己的定稿。箱子、掀舌、沿口以下、人相对箱子的大小不要改。

倒箱的人和箱比例跟端箱是同一把尺子。哭脸不要往近了裁。

## 定稿：啃鸡

[examples/example-takeout-chicken-v1.png](examples/example-takeout-chicken-v1.png)

调用名 **啃鸡**。已点头。出这套就锁这张。不要重出这张肖像。钉的是成人份炸鸡、20cm 的人。

| 钉什么 | 怎么认 | 不要学成 |

| 鸡 | 成人份。盒里的腿接近她坐高。她捧着啃的那根到脸 | 把鸡画成她能一口咬完的迷你块 |
| 人 | 约 20cm，坐微型木凳。人和键盘的比例跟趴键盘同一把尺 | 人跟外卖盒一样大 |
| 表情 | 闭眼开心啃 | 没点名不要改成哭 |

换角色：定稿占一张锁尺度，另一张给她自己的定稿。鸡的大小、小凳、键盘尺子不要改。

## QA

1. 光有颜色，脸和衣服吃到环境色
2. 背景是地方，不是色场
3. 人身，两侧没有人耳
4. 没有 UI
5. 若有成人手：她约 20cm，整只 ≈ 一只手长
6. 端箱：整只在沿口以下；锁 `example-box-held-v1.png`，不是坐箱/探箱那种探头
7. 倒箱：锁 `example-box-fallen-v1.png`。人相对箱子的大小跟端箱一致；头不贴壁；哭脸不要特写放大
8. 趴键盘：锁 `example-keyboard-sleep-v1.png`。头约 4～5 个键宽，没有铺满键盘
9. 啃鸡：锁 `example-takeout-chicken-v1.png`。鸡是成人份；人和键盘的比例跟趴键盘一致
10. 其它动作：读 [poses.md](poses.md)，锁对应例图。桌上相对键盘跟趴键盘/桌小同一把尺。特写是近景，不当全身尺度
