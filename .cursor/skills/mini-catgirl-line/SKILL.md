# 迷你猫娘·勾线

先读 [mini-catgirl-body](../mini-catgirl-body/SKILL.md)，再套本套线。

**命根子：线清楚，色较平。** 比色彩挺，比厚涂图形。可以白底或浅色场。身子仍是迷你。

衣发眼表情从 [wardrobe.md](../mini-catgirl-body/wardrobe.md) 另抽。这套样本里 wow 嘴、小笑更常见，仍从池子抽，不要张张同一张脸。

## 英文模板

```
Clean graphic chibi illustration. Visible soft-black or colored outlines, flatter local color, simple cel-like shading, crisp silhouette. White or pale background, or a simple color field. Cute sticker / model-sheet energy. Not oil impasto, not cinematic shallow DOF, not candy sparkle overload, not photoreal. Do not name any app, model, or commercial art preset.

{FACE}
{BODY}
{EARS}
{HAIR}
{EYES}
{EXPRESSION}
{OUTFIT}
{LIMBS}
{SUBJECT}

Centered character. Vertical 9:16. One mini character only unless the user asked for a box of several. No UI, no watermark, no text.
```

## 本地锁

没有脱敏复刻稿时先出一张再锁。`o_031` 用户已放进风格Ⅱ，不要再当勾线锁。根目录未分类（如 `o_025`、`o_047`）不要当本套锁，除非用户点名。

外发只用后来复刻的 `参考图/_*.png`。

## QA

- 线看得见
- 色块清楚，不是喷枪夜景
- 身子仍迷你
- 身子 QA 过

## 不要

- 漂成厚涂没线，或色彩大环境染色
- 提示词写品牌名
