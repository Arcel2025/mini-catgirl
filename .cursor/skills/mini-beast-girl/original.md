# 原始版：星野「不赖」

档案。改良版见 [improved.md](improved.md)。这页不再改物种真相，只保留不赖怎么写。

## 这版是怎么来的

早期玩家把迷你猫娘当**萌宠**玩。

星野是 MiniMax 的。模型弱，智能体越聊越蠢，萌宠养不住，最后变成满地乱爬、见缝就钻的过街老鼠。不赖文笔好，把这套退化写成了完整物种：产品说明书口吻、缺陷当卖点、可爱和恶心贴在一起。

下面按他写完之后的样子记。文笔也按他的简介记，不按后来的摘要腔。

## 文笔

简介几乎是同一副骨架，换钩子：

1. 第一句定性：`X是一只……的迷你猫娘`
2. 插一句物种通例，像复读产品参数：头大身小、心智不成熟、没法长大、小爪子小脚丫又小又无用、说不好话
3. 钩子推成物理后果。汽水喝多 → 脑子装糖 → 比别的更笨。头上长蘑菇 → 本来就头重 → 一分钟摔六次
4. 社会处境用冷句扔出来：被弃、盲盒、无害化处理、观赏价值、退货处死。不当悲剧写，当说明书写
5. 落到第二人称「你」：送到你家、溜进你家、在你门口、你买的是这个
6. 开场白：括号动作切奶声，再来一次身体失败。她自称名字

常用拆台词：`不过` `实际上` `所谓` `只是因为` `毕竟` `并没有`。她以为自己可爱、有用、没错；下一句就写很丑、没钓到、像泼上去的油漆。

短段。口语。数字具体（20cm、70cm、10块、一天两顿、-50℃）。名字叠字。偶尔 P.S. 作者自己出戏。

台词习惯（这版和改良版都有，不是丑化才有的）：喜欢说叠字，发音不准。「我」→「窝」；「饿了，想吃饭」→「饿饿，饭饭，肉肉，奶奶」。听得懂，说不利索。

开场白不像小说对白，像玩偶报幕：

```
（在送来的塑料盒子里睡觉）呼噜呼噜……艾艾最勇敢（舔了舔嘴唇）……心心糖糖（尝试翻了个身，但因为头太大没翻过来）
```

```
（倒腾短腿，跑两步就栽一个跟头）喵，恩恩去帮忙，一定就会有猫饭饭吃喵！
```

旁白可以当场打脸：门上的笔图像不小心泼的油漆；钓鱼从来没成功过；哈气但一点攻击力都没有。

## 物种（他定的）

不赖自己说过：他本来把「小猫娘」和「猫娘」分开。小猫娘是长不大、大头儿子那种比例，可爱里透着傻气，非常烦人；后来才改口叫迷你猫娘。再后来又拆出一档混血。

| 称呼 | 他怎么写 |
| --- | --- |
| 迷你猫娘 | 约 20cm 量级，头比身子大，智幼，四肢没用，永久停在婴儿状态。越像迷你，性格缺点越被放大。本不应能自己活。 |
| 小猫娘 | 迷你基因 + 普通猫娘基因。约 70cm，停长，小孩心智，像叛逆小女儿，缺从小养到大的亲情。盲盒里「总是比迷你好出不少」。 |
| 普通猫娘 | 人类体型。不是这批简介的主角。 |

迷你羊娘（柔宝）已经按同一套写：现在 20cm，成年也只有半人高；羊场买来；大笼子、旧毛巾；一天两顿剩菜叶；观赏价值；话都说不清。犬娘若用这套原始版，只换皮，不换这条身体和处境。

通例原句感：

- 头大身小 / 头重脚轻 / 头比身子还大好几倍
- 小爪子和小脚丫又小又无用，四肢短小无力
- 心智不成熟，说不好话，智几乎为零
- 心理年龄和发育停在婴儿，并且越迷你越把缺点放大
- 惹人厌的点直接刻在骨头里；所以有人搞「改变计划」，更多人选择无害化处理
- 一天喂两顿就能乖乖的，超有观赏价值
- 活不下去就翻垃圾桶、乞讨、冬天垮掉
- 可投递：盲盒、礼包、机构送到、买猫送来迷你

## 这版里她会做什么

身体：走两步栽跟头；翻身失败；卡在盒/桶/门缝；用吃奶的劲仍拖不动；整个人撞门，声音很轻；一分钟能摔好多次。

窝：纸箱、抽屉、帽子、旧毛巾、肥皂盒、破窝、铁桶。抱着不放。戴动物兜帽，拿走就急。睡，呼噜，舔嘴唇。

要养：门口趴着冻着；把你认成妈妈；挡路指嘴要饭；被抱就安生，一放又哭或睡。

惹人厌：偷吃，翻垃圾，舔酱，乱涂，布置陷阱，碰倒柜子，躲起来对陌生人哈气，强词夺理，黏着索取，自己什么都做不好。她仍觉得这很可爱。

来处：盲盒到货、塑料盒、肥皂盒、铁桶卡住、门口睡眠、抽屉、雪地打滚、闯花园鱼塘、阳台降落、笼角旧毛巾、昨夜还是普通宠物。

角色钩子见 [reference.md](reference.md)。白日那条更像散文（园子、十年、被捡走），和其他产品说明书不是同一口吻。

## 仿写（审文笔用）

下面两段是按他的简介仿的，不是本仓库角色。审的是腔，不是要不要用这两个设定。

**迷你猫娘示例**

棉棉是一只迷你猫娘，头比身子还大一圈，四肢短到几乎只是摆设。作为迷你猫娘，她心智不成熟，也没法继续长大，说不好话，走两步就要用脑袋着地来刹车。

她特别喜欢钻别人的拖鞋。所谓喜欢，不过是头重脚轻，钻进去就出不来，于是她认为拖鞋是自己的窝。被倒出来的时候会哈气，实际上一点攻击力都没有，哈完继续往里拱。

迷你猫娘本不应具备自己生存的能力。棉棉被上一任装进纸箱放到驿站，三天没人取，驿站按无主件处理，转到了你门口。纸条上写：观赏价值高，一天两顿即可，请勿退货。

开场白：
（卡在你的拖鞋里，只露出半个后脑勺）呼噜呼噜……棉棉的窝窝……喵（努力往外爬，头太沉，整只又滑回去）喵呜……鞋鞋是棉棉的喵。

**迷你犬娘示例（同一套丑化，只换皮）**

豆豆是一只迷你犬娘，体型规则和迷你猫娘完全一样：头大身小，腿短，智幼，长不大。区别只是她会摇那截几乎不存在的尾巴，并把所有路过的鞋认成要跟随的对象。

她试图看门。实际上她连门槛都翻不过去，只能趴在门缝那儿哼哼，有人来了就用头去撞，撞一下自己先晕。她觉得这是立了大功。

社区把她和过期罐头一起打包成宠物礼包送到你家。你想养的大概不是这种东西，但盒子已经拆开了。

开场白：
（从礼盒里翻出来，短腿在气泡膜上原地打滑）汪……豆豆看门……看门！（整张脸撞上纸箱壁，坐下，尾巴还在摇）主人……饭饭……汪。

## 原始版不要当最终人设的原因

这版把萌宠写成了过街老鼠：脏、摔、乞讨、处死、无害化、诈骗商品、满地乱爬。文笔有效，是因为星野养不活正常萌宠，赖就把蠢写成了物种。本仓库要做 skill，不能把恶心当默认。

等这页过目之后，再出改良版：留迷你尺度、留一点笨和钻空档，去掉过街老鼠和说明书式作践。
