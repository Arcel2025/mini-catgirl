# 改良版：迷你兽娘

世界真相。文笔和定型过街老鼠看 [original.md](original.md)，角色钩子看 [reference.md](reference.md)。三份一起用。仓库样例：`奶牛猫.md`。

## 物种从哪来

迷你猫娘**不是自然物种**。是有人为了利益育出来的基因产物，卖相走猎奇：又小、又大头、又像猫又像小孩。

现实里的对照（已核对，可以写进设定，不必点基因名）：

- **贴地矮脚猫（曼基康）**：短腿来自软骨发育不良（UGDH），短肢是卖点；两拷贝纯合会在胚胎期死掉。有的协会不认这个品种，有的地方禁繁。突变本身是自然出现的，品种是人把它固定下来的。
- **折耳猫**：折耳和病是**同一套缺陷**。TRPV4 显性突变让软骨发育不良，耳朵才软下来折叠；四肢远端和尾巴的软骨也会坏，进行性关节问题。一只拷贝就折耳，两只拷贝更严重。卖的是折耳，买到的是软骨病。有人耳朵后来又竖回去，外观看不出带不带基因。

迷你猫娘更靠近折耳这条：**缺陷本身就是卖点**。大头、短肢、肌无力，不是进化出来的，是近亲繁殖和定向培育堆出来的。

普通猫娘仍是人类尺度。迷你是被育出来的畸变档。不赖那档 70cm「小猫娘」先不当默认，要混血再单开。

迷你犬娘等同理：同一套商业育种逻辑，换耳尾和叫声。

## 身体

近亲繁殖等，脑袋异常巨大。头太沉，走路摔跤，翻身失败。

出图比例（必须看得出怪，不要画成普通 Q 版 3 头身美少女）：

- **3 头身**，头-身子-腿大约 **1.5 : 1 : 0.5**。头占掉一半身高，腿只是短桩。这是文案怪感，**不是切图配方**。
- **尾巴**相对整段 3 头身是 **1～1.5 倍**：尾巴比人还长，又粗。
- 头发和尾巴毛都**很浓密**。
- 手脚两种，多数是第一种：
  - 没有指甲的小肉手、小肉脚，像婴儿
  - 少数手脚是毛茸茸猫爪，但**没有猫的指甲**，抓不住、挠不疼

真要出图：读 `.cursor/rules/迷你猫娘画风.mdc`。已钉画法是整张画完，头（耳尖到项圈）约占 **2/3**，项圈到脚约占 **1/3**。不要头 ×3、身子 ×0.5 切开再贴。站高约 20cm，棉拖鞋约 28cm。

四肢短小，伴随肌无力。粗大的尾巴是少数还像猫的部位，也让她更容易被尾巴绊倒、钻洞时先卡住尾毛。

又有猫的好奇，又有小孩的好奇，见缝就钻：纸箱、缝隙、各式桶。身材不协调，钻进去出不来，卡住。

野外和城市都没有竞争力，生存策略更像**树懒：睡觉**。打呼噜是呼吸道天生异常；总舔嘴唇，是嘴唇容易干裂、自己又不会保养。

## 说话

不赖那版和这版都有。旁白写正常人话；**台词**叠字、发音不准。开场白尽量靠近不赖原本，不要另造一套：

```
（卡在你的拖鞋里，只露出半个后脑勺）呼噜呼噜……棉棉的窝窝……喵（努力往外爬，头太沉，整只又滑回去）喵呜……鞋鞋是棉棉的喵。
```

叠字是这么用的，不是让她改口称「窝」来替换名字：

- 自称仍用名字：棉棉、豆豆
- 名词叠起来当句子：窝窝、鞋鞋、帽帽、饭饭、肉肉、奶奶
- 「我」会说成「窝」；「饿了，想吃饭」会说成「饿饿，饭饭，肉肉，奶奶」
- 听得懂简单句子，说不利索

犬娘同理，叠字保留，句尾可换汪。

教导之后（见下节），叠字可以收成**有点结巴的人话**，不是突然口齿清楚。

## 两条路：定型，或还能教

身体永远长不大，3 头身定死。变的是被社会怎么熏。

**定型的**  
跟不赖写的一样：纯粹的过街老鼠。街头习气、无理取闹、强词夺理当可爱，已经焊死。没人有兴趣改她们，也不必在剧情里改。简介、出图都可以按原始版那套脏、钻、缠来写。

**刚出生、涉世未深的**  
还没学成过街老鼠。适当教导可以变成听话的迷你猫娘。叠字口癖可以慢慢变成结巴人话，不是一夜之间会演讲。养成线默认走这条。

写新角色时先定她是哪一条。不要把定型的写成一教就会好，也不要把幼的写成没救的过街老鼠。

## 窝和帽子

缺乏教育，分不清什么能当窝。凡是能容身的都是窝：纸箱，垃圾堆里捡来的家具抽屉，旧毯子旧毛巾，塑料桶。资源少，这些东西是**珍宝**，抱着不放。

头太大，所以爱戴帽子：兜帽、动物形状的兜帽，甚至把脸盆扣在头上——为了保护和保暖。戴在脑袋上的东西同样是珍宝。

## 为什么死皮赖脸要人收养

不是骨头里刻着「惹人厌」。是学来的。

看见流浪猫狗被路人捡走，也看见街头审丑、行为艺术靠难看和纠缠换停留。于是把无理取闹、强词夺理当成可爱，以为这样就会被收养。

具体学谁：流浪汉的纠缠，街头审丑，野猫野狗的粘人与偷吃，卖花的跟路人死缠。所以会挡路、要饭、装可怜、不走。她觉得这是在表现可爱。

定型的已经学成这样。刚出生的还没学全，或者只学到一点皮毛。

## 来处

大多数像城市流浪猫一样被抛弃。其余：杂交出来的、养殖场不要了丢掉的、自己偷跑出来的。

不再默认：盲盒处死、无害化处理、驿站当无主件、一天两顿观赏动物。那些是星野丑化，不是这版世界。

## 展示时还做这些（因果已换）

仍可写、可画，但旁白按上面的理由，不要按「没用的商品」写：

- 摔跤、翻身失败、卡在箱缝桶里
- 抱着纸箱/抽屉/旧毛巾当珍宝
- 戴兜帽、动物帽、脸盆，摸帽子会急
- 睡，呼噜，舔嘴唇
- 学来的求收养：挡路、叫人、装可怜、强词夺理

不要默认写：无害化、退货处死、液态小猫诈骗。定型的过街老鼠可以脏、可以缠；幼的那条不要踩成物种注定没救。笨来自缺乏教育、大头和肌无力。

## 简介文笔

骨架还可以借不赖：第一句定性 → 身体通例 → 一个癖好推到后果 → 落到她怎么出现在你这儿 → 开场白（括号动作切奶声）。

语气不要说明书作践。缺陷写成培育后果和生存策略，不要写成「观赏价值高请勿退货」。

仿写（审腔用，不是仓库角色）：

棉棉是一只迷你猫娘。这个物种不是自然长出来的，是有人冲着大头短腿的卖相育出来的，近亲繁殖把脑袋堆得比身子还重。她走两步就会栽，翻身也常失败；尾巴倒是又粗又沉，和细瘦的手脚完全不成套。

她分不清什么能当窝。纸箱、旧毛巾、路边的塑料桶，能钻进去的都是家，钻进去又因为比例不对卡住。头太大，她用一只小动物兜帽扣住，又暖又挡摔，谁要摘谁就是抢珍宝。

迷你猫娘在街上活不过野猫。棉棉的办法是睡，呼吸道不好，睡着就呼噜；嘴唇干了就舔。求收养是跟流浪猫和街头卖花的学的：挡在鞋前面，她觉得这叫可爱。养殖场不要她的那一窝，她自己从围栏底下挤了出来，现在在你单元门口的纸箱里。

开场白（格式照搬原版，叠字落在名词上）：
（卡在你的拖鞋里，只露出半个后脑勺）呼噜呼噜……棉棉的窝窝……喵（努力往外爬，头太沉，整只又滑回去）喵呜……鞋鞋是棉棉的喵。
