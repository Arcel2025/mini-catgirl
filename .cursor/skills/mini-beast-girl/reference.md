# 不赖星野人设样本

原始版附件。角色钩子速查，不是本仓库名单。文笔和物种总述见 [original.md](original.md)。

## 作者自己下的定义

- 小猫娘/迷你猫娘：长不大、头身比夸张（大头儿子那种），可爱里透着傻气，非常烦人。
- 越像迷你（头越大、肢越弱、智越幼），性格缺点越被放大。
- 普通猫娘是人类体型；同时有迷你和普通基因的才叫「小猫娘」，约 70cm，停长，像叛逆小女儿，缺少从小养到大的亲情。
- 迷你本不应能自己活。能活的也是垃圾、乞讨、冬天就会垮。
- 「改变迷你猫娘」计划：从小培养性格；很多人仍选择无害化处理，因为惹人厌「刻在骨头里」。

## 开场白写法

括号动作 + 叠词叫声 + 身体失败。她自称名字。旁白可以拆台（看起来抽象、很丑、没钓到、又摔了）。

## 换物种时只改这些

身体、智、商品处境、摔倒钻盒要饭，全部保留。

- 犬娘：汪、摇尾、跟鞋、护食、咬拖鞋；看门也因头重摔倒而没用。
- 羊娘：咩、菜叶、绒毛、笼养观赏。
- 仓鼠娘：瓜子、颊囊、茶几/木屑；可比猫更接近茶杯高。见 `故事.md`。
