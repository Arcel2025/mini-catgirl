# 每次另抽：衣服、发型、眼睛、表情

身子锁见 [SKILL.md](SKILL.md)。用户指定了就用指定的。没指定就各抽一项，不要张张白毛衣、蓝眼、发呆。

半写实那桶（女仆、校服、哥特）可以从这里借衣服，**头身仍按身子锁**。

## 衣服

衣服大一号，淹那一小截身子。领口、纽扣、背带画清楚。

| 抽到 | 站着的鞋 |
| --- | --- |
| 白衬衫 + 黄背带短裤 | 白圆头童鞋 |
| 粉裙校服 + 领结 | 白短袜 + 黑玛丽珍 |
| 水手服 | 白童鞋或玛丽珍 |
| oversized 卫衣 + 短裤 | 白面包鞋 |
| 连体衣 / 睡衣 | 自带脚套或小凉鞋 |
| 和风交领 / 浅色罩袍 | 可藏进衣摆 |
| 动物兜帽大衣 | 白袜或小靴 |
| 女仆裙 / 小哥特（黑白或黑粉） | 玛丽珍 |
| 空白 oversized 白 T + 红项圈金铃 | 小肉脚或童鞋 |
| 破一点的 oversized 裙或袍 | 跟四肢开关走 |

站着必须有鞋、爪或赤脚。幼童鞋：圆头、简单、略大。

不要：成人运动鞋鞋带、高跟、长筒靴拉链；连续两张同一套。

钻箱 / 杯 / 桶可以不露脚。

`{OUTFIT}` 例：

```
Outfit this time only: navy sailor dress, oversized, swallowing the tiny torso. White chunky round-toe toddler shoes, slightly too big. No adult sneakers, no laces, no heels.
```

## 发型

发量足，当云画。剪裁每次换。

| 抽到 | 写法 |
| --- | --- |
| 短云 + 一缕呆毛 | short fluffy cloud hair, one ahoge |
| 齐肩波波 | fluffy bob |
| 双马尾 | short twin tails, still voluminous |
| 侧辫 / 双辫 | loose braids, hair still full |
| 长发垂下（可拖地） | long hair as color volumes, can touch the ground |
| 刘海盖额 | bangs over the huge forehead |

发色另抽：白、银、浅粉、浅蓝、奶茶棕、黑、奶牛黑白斑（只在头发上）。

不要：贴头皮的稀发；耳上画斑；把叠字写进衣服。

## 眼睛

仍然只有两只，仍然很大（大约脸的三分之一），圆瞳，每眼两颗高光。**颜色和情绪另抽。**

瞳色：蓝、绿、琥珀、粉、红、紫、金。

情绪（和表情配对）：

| 抽到 | 写法 |
| --- | --- |
| 玻璃珠 | wet glass-bead, two catchlights |
| 水汪汪要哭 | extra gloss, small tear at the corner |
| 眯成一条缝 | happy or eating, still two eyes |
| 吃环境色 | iris stained by nearby light（色彩 / 厚涂） |
| 干净马卡龙瞳 | bright local color, no stain（多巴胺 / 勾线） |

不要：竖瞳（除非用户点名兽化）；额头第三只眼；把「第三颗星高光」写成 third eye。

```
Exactly two eyes, never a third eye on the forehead. Huge round glossy eyes about one third of the face each. Soft gradient iris, dark rim, round pupil. Two catchlights per eye, one large upper and one small lower.
Iris color this time: {EYE_COLOR}. Eye mood this time: {EYE_MOOD}.
```

## 表情

默认池，每次抽一个。用户要笑就笑，要睡就睡。

| 抽到 | 嘴 / 脸 |
| --- | --- |
| 愣 | 一小条嘴，看镜头 |
| 小 wow | 小圆嘴，轻轻张开 |
| 轻怕 | 微张，一点汗 |
| 闭眼睡 | 弯眼，小微笑 |
| 一线笑 | 小小的上扬，不要大笑露龈 |
| 委屈撇嘴 | 一小条往下撇 |
| 咬下唇吃惊 | 齿关轻轻咬住下唇 |

不要：媚、怒到变形、成人性感；勾线那套可以更 round wow，厚涂可以更湿。

```
Expression this time only: {EXPRESSION}. Still a toddler face. Not sexy, not enraged, not a wide adult grin.
```
