# 迷你猫娘身子锁

几套画风共用这一具身子。先读本文件，再读用户点的风格 skill。

| 钉死 | 每次另抽 |
| --- | --- |
| 头身、四肢、兽耳位置和大小 | 衣服、发型、眼睛颜色/情绪、表情 |
| 人脸（不要猫吻） | 发色、瞳色、嘴型在池子里换 |
| 肉手 / 兽爪必须写死 | 鞋跟衣服走 |

半写实那 11 张（蓝外套、校服、哥特女仆）**只借衣发表情，不借头身**。兽身三张、非立绘三张不锁。

## 钉死：头身四肢

大头，短身子。脖子看不见。身子是**一小截**，被大一号衣服淹住，不是肥胖球体。胳膊短，袖子里只露小手。腿是短桩，常被衣服或鞋吃掉。坐下、蹲下、钻盒时身子再缩，画面里几乎只剩头。

本地可以写大约 2～2.5 头身。豆包会往正常小孩收，大约 80% 就停，**不要反复加头身数字去拧**。

怎么漂：3～4 头身校服小孩；7 头身；细长四肢；圆球小胖子；人脸安在猫身上趴地。

```
Super-deformed chibi. Neck hidden. A SMALL short torso hidden inside oversized clothes — the clothes are big, she is tiny. Not a spherical fat belly, not obese, not an inflatable ball. Stubby arms and stubby legs. Not a normal child, not a 3-to-4-head schoolkid, not skinny fashion limbs. Human girl standing or sitting, never a cat body with a human face.
```

斑斑 / 兜兜 / 小委屈 / 拖鞋有各自锁图时，头身跟那只的锁，不要用这句去压。

## 钉死：兽耳

耳只长头顶，从头发里戳出来。耳尖明显高于头顶。

| 谁 | 耳朵 | 和头比 |
| --- | --- | --- |
| 猫娘 | 一对偏大尖三角猫耳，外侧跟毛色，内侧透粉 | 单耳高度约头（不含耳）的 **1/3～1/2** |
| 鼠娘 | 一对偏大圆盘鼠耳，粉、半透明 | 单耳宽度可接近脸宽一半 |
| 仓鼠娘 | 一对又大又圆的仓鼠耳 | 只留耳和一小团尾；脸上身上不要绒 |
| 羊 / 兔 / 狐 | 跟物种：圆羊耳、长兔耳、尖狐耳 | 仍然只长头顶，偏大 |

怎么漂：耳太小像发卡；耳上涂奶牛斑；牛角；侧头长耳；第三只耳。

猫默认：

```
Two LARGE pointed cat ears on top of the head only. Each ear is about one third to one half the height of the head. Pink translucent inner ears. Ear tips well above the crown. No horns, no extra ears, no markings on the ears.
```

## 钉死：脸型（不是表情）

人脸，圆饺子脸，额头大、下巴短、婴儿肥。点鼻或没鼻。腮红两团。

怎么漂：猫吻、三瓣嘴、ω 嘴、兽鼻、胡子、口鼻前突。

```
Human toddler face only. Round dumpling face, huge forehead, short chin, heavy two-patch blush. Tiny dot nose or no nose. Tiny human mouth. No cat muzzle, no snout, no feline nose leather, no whiskers, no ω-mouth, no split lip.
```

## 钉死：肉手 / 兽爪

不许随机。没说就肉手。

| 用户说的 | 写什么 |
| --- | --- |
| 没说、肉手 | 婴儿肥人手，3～4 短圆指，没指甲。脚是童鞋或小肉脚 |
| 猫爪、兽爪、肉垫 | 手脚同一套短毛爪，肉垫，不穿鞋 |

不要一只人手一只爪。不要又画鞋又伸出爪子。

## 钉死：尾巴跟物种

猫尾很蓬、比身子长。鼠尾细、粉、**没毛**。仓鼠一小团。不要统一加毛。

头发要够量、当体积画。**发型可以换**（短云、双马尾、辫、拖地长发），不要改成贴头皮的稀发，除非用户点名。

## 每次另抽

用户没指定就从 [wardrobe.md](wardrobe.md) 各抽一项。连续两张不要同一套衣服、同一个发型、同一张脸。

```
- [ ] 风格 skill
- [ ] 谁：猫 / 鼠 / 仓鼠 / 其他
- [ ] 四肢：肉手（默认）/ 兽爪
- [ ] 衣服 + 鞋（新抽）
- [ ] 发型 + 发色（新抽）
- [ ] 瞳色 + 眼情绪（新抽）
- [ ] 表情（新抽）
- [ ] SUBJECT（姿势、地点、道具）
- [ ] GenerateImage 9:16；提示词不含品牌名
```

## 工具

`GetDynamicTools` → `namespace=cursor`，`toolName=GenerateImage`。再 `CallDynamicTool`，不要带 `mcpDetails`。

`description` 英文：身子锁 + 风格模板 + 这次抽到的衣发眼表情 + SUBJECT。禁止写星野 / Xingye / MiniMax / 官方画风名。

候选落到 `参考图/_名字-vN.png`。没点头不进 `养成桌宠` 的 `pet.json`。

## QA（身子）

1. 头身仍是迷你，不是 3～4 头小孩，不是圆球小胖子
2. 耳够大，只长头顶
3. 人脸，不是猫吻，不是兽身
4. 衣服和上一张不一样
5. 爪和开关一致
6. 尾巴跟物种走

风格另有自己的 QA。
