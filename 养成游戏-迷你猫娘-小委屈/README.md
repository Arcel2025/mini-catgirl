# 养成游戏 · 迷你猫娘 · 小委屈

客厅里那只白 T 奶牛猫。不是斑斑，不是兜兜。

需要 Python 3.12 或 3.13，以及 pillow：

```
pip install pillow
```

能玩的主循环改成网页日常房间，设计见 `html日常.md`。Python 窗口仍能播第一章，新日常不要往那扇窗上加。

过日子打开 `打开日常.bat`，进 `web/` 客厅页。点她摸摸，点碗喂，拖到落点。沙发和桌子只是底图。

双击 `启动.bat` 仍是 Python 窗口播第一章。点一下出下一句。看到「喵喵？ 什么……有意思？」之后，选是否收养她。选「是」接到阳台和「第一章结束」。选「否」的两条坏结局还没接。

| 文件 | 管什么 |
| --- | --- |
| `小委屈.md` | 人设、简介、开场白 |
| `小委屈故事.md` | 养成剧情（第一章：初遇） |
| `html日常.md` | 网页小游戏：房间日常、存档、和静帧怎么分 |
| `packs/xiaoweiqu/` | 能玩的人物包 |
| `app.py` | 养成窗口（第一章） |

窗口存档写在 `packs/xiaoweiqu/save-*.json`。网页存档走浏览器 `localStorage`，不要把任一种存档提交上去。
