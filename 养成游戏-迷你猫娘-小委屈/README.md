# 小委屈 · 两套游戏

客厅里那只白 T 奶牛猫。不是斑斑，不是兜兜。同一只角色，两套游戏，现在还挤在这个文件夹里。

**线性剧情。** 点一下下一句。第一章见 `小委屈故事.md`，窗口 `启动.bat` / `app.py`。图是 9:16 静帧。没有体力条。

**体力养成。** 房间里过日子。对照小红书纸箱猫。设计见 `html日常.md`，打开 `打开日常.bat`。图是竖贴纸。有饥饿、清洁、心情、健康、体力。新日常不要往剧情窗口上加。

需要 Python 3.12 或 3.13，以及 pillow：

```
pip install pillow
```

日常竖贴纸（站、走、跑、坐、喘气、作揖）画布必须是 `864×1152`。换图之后在 `web/` 跑 `python check_stickers.py`。

过日子打开 `打开日常.bat`。画面在左，右侧是管理栏。点她摸摸，点饭盆倒粮。

双击 `启动.bat` 播第一章。点一下出下一句。选「是」接到阳台和「第一章结束」。选「否」的两条坏结局还没接。

| 文件 | 管什么 |
| --- | --- |
| `小委屈.md` | 人设（两套共用） |
| `小委屈故事.md` | 线性剧情第一章 |
| `html日常.md` | 体力养成 |
| `packs/xiaoweiqu/` | 现在还共用的人物包 |
| `app.py` | 剧情窗口 |
| `web/` | 养成网页 |

窗口存档写在 `packs/xiaoweiqu/save-*.json`。网页存档走浏览器 `localStorage`，不要把任一种存档提交上去。
