# 养成游戏 · 迷你猫娘 · 小委屈

客厅里那只白 T 奶牛猫。不是斑斑，不是兜兜。

需要 Python 3.12 或 3.13，以及 pillow：

```
pip install pillow
```

双击 `启动.bat`。新游戏会播第一章。点一下出下一句。看到「喵喵？ 什么……有意思？」之后，选是否收养她。选「是」是好结局：进来、摔狗啃泥、放到阳台，说完「会乖乖的」后淡出「第一章结束」。过日子菜单还没开。选「否」的两条坏结局还没接。

| 文件 | 管什么 |
| --- | --- |
| `小委屈.md` | 人设、简介、开场白 |
| `小委屈故事.md` | 养成剧情（第一章：初遇） |
| `packs/xiaoweiqu/` | 能玩的人物包 |
| `app.py` | 养成窗口 |

存档会写在 `packs/xiaoweiqu/save-*.json`，不要把存档提交上去。
