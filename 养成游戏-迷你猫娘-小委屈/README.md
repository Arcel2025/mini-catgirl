# 养成游戏 · 迷你猫娘 · 小委屈

客厅里那只白 T 奶牛猫。不是斑斑（绿化带），不是兜兜（雪街）。

| 文件 | 管什么 |
| --- | --- |
| `小委屈.md` | 人设、简介、开场白 |
| `小委屈故事.md` | 养成剧情（第一章：初遇） |
| `养成桌宠/packs/xiaoweiqu/` | 能玩的 pack（引擎只认这里） |

玩：把 `养成桌宠/packs/active.txt` 写成 `xiaoweiqu`，再双击 `养成桌宠/启动.bat`。要回兜兜就写成 `doudou`。

模板 `packs/example/` 仍叫喵喵，给测试用，不要改成她。
