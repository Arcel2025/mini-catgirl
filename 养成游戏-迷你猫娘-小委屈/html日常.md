# 小委屈 · HTML 日常

能玩的主循环改成网页小游戏。对照是小红书「纸箱猫」的房间页：固定场地、角色贴纸、点一下换一句。不是图鉴，不是抽卡。

人设见 `小委屈.md`。第一章分镜见 `小委屈故事.md`。生命数字见 `life/tables.py`，抄进网页时数字不要另编一套。

Python 窗口（`app.py`）仍能播第一章，新日常不要往那扇窗上加。朋友玩的是网页。

## 两层

**日常。** 打开之后一直停着的那一页。俯视客厅铺底。她是贴纸，碗是热区。点、拖、自己晃。底下换一行字。顶上走饥饿、清洁、心情、健康。沙发和桌子画在底图里，不当热区。

**事件。** 第一次偷吃、起名、项圈这些，才切现在的 9:16 静帧。播完回到房间。日常点一次喂，只换贴纸和底栏，不黑屏、不换海报。

## 壳

普通网页。HTML 铺房间，JavaScript 算生命核、坐标、存档。不需要 React，不需要游戏引擎，不租云服务器。

给朋友：静态托管（GitHub Pages 一类）发链接。小红书小工具以后是同一套离线页，只是打包方式不同。存档在对方浏览器里。

本机开发：文件夹打开即可。图继续用 `packs/xiaoweiqu/assets/`。剧情继续吃 `packs/xiaoweiqu/options.json`。

## 存档

浏览器 `localStorage`。JSON 字段沿用现在的 `Save`：`vitals`、`gold`、`flags`、`life_phase`、`last_simulated_at`、`rng_state`。打开页先按上次时间把离开的那段补上，跟现在窗口同一套核。

房间另加：

- 她在哪个落点（地毯 / 碗边 / 窗边 / 沙发前）
- 当前贴纸（站 / 走 / 吃）
- 碗里还有没有粮
- 底下那行字

三档档案三个键。页面要能导出、导入 JSON 文件。换手机、清缓存、无痕模式会丢档，导出是备份。不要云存档。

## 日常页

第一章字卡「第一章结束」之后进这一页。进房间时打开 `daily_life`。不等第二章写完。

**看见的。** 底图用横版俯视空客厅 `living.png`，铺满整屏。她是站姿贴纸 `stand.png`，远小于沙发和餐桌。碗是单独热区。字和按钮叠在画面上下。训斥、罚站、吃药、复活收进二级。沙发、茶几、餐桌只画在底图上，不当贴图、不点。第一版不要「去茶几底下钻」。

**点的。**

- 点她：摸摸。心情加一点。只换底栏。数字 `PET_MOOD` 写在 `web/life.js`，表里没有这一项。
- 点碗：喂。她平移到碗边，贴纸轻轻抖。扣金币、加饥饿，数字用现表。底栏写吃，铃铛写在字里。
- 拖她：只落到地毯、碗边、窗边、沙发前的地板。不是满屋物理，也不点沙发和桌子。

你不点，时间也走。她会自己晃、自己进箱、自己饿。擦拭仍护项圈，底栏说「项圈……不摘喵」，不为此切特写。

**贴纸。** 站、走（两帧迈腿）、坐着抱碗吃。日常全靠这几张在坐标上换。不要为每一次喂、摸出一张 9:16。箱里坐、摔趴以后再拆。

## 以后才做

玩具是房间物件：地上一张图，谁占用、玩多久。不是新一章分镜。

再进门的迷你猫娘是住客，两三只封顶。每人五张贴纸加短档案（会不会偷吃、爱钻哪）。粮食是屋子的，碗只有一个。第一次偷吃可以切静帧，第五次只记底栏和小事。不要做成收藏 200 只、换住客、收藏值。

## 不做

- 把 tkinter 窗口当房间舞台
- 为日常每一动切整张立绘或黑屏过场
- 网页前端再挂一台 Python 云服务器
- 纸箱猫的开箱、图鉴、换住客

## 先做哪一块

客厅页在 `web/`。双击 `打开日常.bat`，或浏览器打开 `web/index.html`。存档读写（localStorage，导出导入）和客厅能点、能喂、能摸，已经先做。第一章从现有 `options.json` 接进同一张网页，还没接。新分镜先不动。
