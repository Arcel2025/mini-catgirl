# 小委屈 · HTML 日常

这是体力养成，不是线性剧情。对照是小红书「纸箱猫」的房间页：固定场地、角色贴纸、点一下换一句。不是图鉴，不是抽卡。不要把第一章的海报、摔跤、打工菜单搬进来。

人设见 `小委屈.md`（两套共用）。剧情分镜在 `小委屈故事.md`，那是另一套游戏。生命数字见 `life/tables.py`，抄进网页时数字不要另编一套。

Python 窗口（`app.py`）只播剧情。新养成不要往那扇窗上加。朋友玩的是网页。文件夹以后要拆，现在还挤在一起。

## 两层

**日常。** 打开之后一直停着的那一页。房子是主循环：客厅、阳台、以后的房间，各一张空景底图。你进哪间，只渲染那间在场的贴纸。饭盆可拖、点一下倒粮。底下换一行字。顶上走饥饿、清洁、心情、健康。沙发和桌子画在底图里，不当热区。

**事件。** 养成里点一次喂，只换贴纸和底栏，不黑屏、不换海报。偷吃、起名、项圈若要 9:16，走剧情那一套，不要默认接到这页上。

## 壳

普通网页。HTML 铺房间，JavaScript 算生命核、坐标、存档。不需要 React，不需要游戏引擎，不租云服务器。

给朋友：静态托管（GitHub Pages 一类）发链接。小红书小工具以后是同一套离线页，只是打包方式不同。存档在对方浏览器里。

本机开发：文件夹打开即可。图继续用 `packs/xiaoweiqu/assets/`。剧情继续吃 `packs/xiaoweiqu/options.json`。

## 存档

浏览器 `localStorage`。JSON 字段沿用现在的 `Save`：`vitals`、`gold`、`flags`、`life_phase`、`last_simulated_at`、`rng_state`，网页另加 `inventory`（背包）。打开页先按上次时间把离开的那段补上，跟现在窗口同一套核。

房子另加 `house`：

- 你在看哪一间（`view`）
- 住客表：每只在哪间、哪个落点、贴纸、坐标、怎么叫用户（测试只有小委屈）
- 碗里还有多少粮（0–10）
- 饭盆在哪一间、坐标
- 底下那行字
- 时段、季节、灯开没开；默认跟设备系统时间，玩家可手改

档里最多二十只。场上只画当前房间里的人。旧档只有 `room` 的，读进来当成她在客厅。

页面只看当前这一档。齿轮弹窗里是金币、时间、背包；仍可导出、导入 JSON。换手机、清缓存、无痕模式会丢档，导出是备份。不要云存档。旧的二三档键如果还在浏览器里，页面不再提供切换。

## 日常页

第一章字卡「第一章结束」之后进这一页。进房间时打开 `daily_life`。不等第二章写完。

**看见的。** 先测两间：横版俯视空客厅 `living.png`；横版空阳台 `web/assets/balcony.png`（按平面图晒衣阳台新出，不是第一章竖图拉长）。第一章 `ch1-balcony.png` 仍是 9:16 剧情图。房子怎么连看 `packs/xiaoweiqu/assets/house-floorplan.png`。画面贴左边。能去的地方在画面顶上那条黑边。右侧固定管理栏：小地图只看（红点是她，蓝标是你，不点开）、顶上黑条最右边齿轮打开当前存档（金币、时间、可折叠背包；导出导入）、小委屈卡片标题行写名字和位置，折叠也能看见她在哪；五项条：饥饿、清洁、心情、体力仍是 80–100 红，40–80 绿，10–40 浅绿，0–10 灰。健康条取消红段，80–100 也用绿（40–80 同色），10–40 浅绿，0–10 灰；健康到 0 直接死亡，换死亡静帧，不要把站姿转倒。底栏只留一句。她开口一律「名字：台词」，例如「小委屈：人人……饿饿……」。金币不够、那边有吃饭的声音这类系统句不带名字。她是站姿贴纸 `stand.png`。客厅里远小于沙发和餐桌；阳台上同一贴纸大小，不近大远小。不锈钢饭盆可拖到地上任意位置，吃饭贴纸和站姿一样大。沙发、茶几、餐桌只画在底图上，不当贴图、不点。不要「去茶几底下钻」当打工。靠近茶几以后只换一句，不扣不赚。房间空景还没锁，顶上先只放能去的地方。

以后每区只画能互动的那一块，16:9，45 度斜俯视：场地填满画面，周围房间裁掉，椅子沙发只从边上露一截。不要 90 度顶视。人物贴纸不改，站在场地上。餐厅空景已锁 `web/assets/dining.png`（台面撑满，画风同客厅傍晚），还没接到切房间。接到以后她站在桌面上；现在客厅那块 `table` 仍不准走。客厅沙发区、卧室床按同一套镜头，等地图简化后再出。

**点的。**

- 点她：摸摸。心情加一点。只换底栏。数字 `PET_MOOD` 写在 `web/life.js`，表里没有这一项。人不在这间就摸不到。不要因为站着就加速扣体力。
- 点「坐下」：叫她原地抱膝坐。点「站起来」：叫她站回去。已经是那个姿势、在吃、在跑、在作揖求饭时不听。
- 点饭盆：倒粮动画，存量加满到 10。拖开饭盆，放哪间算哪间，换房间不会把盆带走。饥饿降到 40 且盆里有粮：饭在这间就自己走到盆边。饭在另一间，她不敢离开你，站在原地作揖晃手（换帧），底栏：「小委屈：人人……饿饿……」，一直求到你带她去、或把盆拿到这间。1 点/一只/一次。
- 拖她：走着、跑着也能拖开。按下要专用拖动静帧（未出，不要复用走帧），松手停在放下的位置，不吸到地毯 / 碗边 / 窗边那些格子。睡着了拖也还是纸箱那张，不换走帧。桌子还是先不让当落点。不是满屋物理。
- 点「擦拭」：湿毛巾擦她，她双手护项圈。清洁加一点。只换日常贴纸和底栏，不切 9:16。图未出。厕所抓进去洗澡涂泡泡是另一件事，见下面「以后才做」。
- 点「逗一逗」：她很享受。要专用贴纸（动画或静帧）。图未出。按钮和核里的 `play` 以后接上。
- 体罚：换「体罚中」静帧 1～2 张，加台词。图未出。核里已有训斥 / 罚站 / 不理，网页还没按钮。
- 点「赶走」：加选项。先换求情静帧和台词，不要复用作揖求饭那两帧。还是要赶，再换难过离去静帧，然后她离开这间屋子。图未出。核里惩罚菜单现在没有这一项。
- 点「关禁闭」：开放更多房间之后才做。把她锁在某一间，人可以走，她出不来，也不再跟着你换房间。现在只有客厅和阳台，先不要做。不进这一批出图。晚上没开灯、冬天丢阳台，以后会扣她，数字先不定。
- 切房间：画面顶上客厅 / 阳台。阳台门口也能点回客厅。人去哪间，她就慢慢跟去哪间。关禁闭时不跟。每跟一次扣体力 10、饥饿 10、清洁 10。进门从门口跑；客厅跑到地毯上，阳台从左下门槛跑到地砖中间。出汗脸红狂奔，到位大喘气。腿短，走得大约是原来的十分之一。跟房间时用她自己的称呼叫你，不要说「跟着鞋鞋」。
- 开灯：晚上全黑时用。先罩一层光，不要重出空景。关禁闭以后会用到。网页还没按钮。
- 存档：顶上黑条最右边齿轮，地图左边。弹窗里看当前档的金币、时间、背包（点开才列出内容，没有就显示空），仍可导出导入。齿轮里以后可手改时段和季节。不再切一二三。

你不点，时间也走。她自己换位时不离开你所在的那一间：客厅只在地毯上挪，阳台只在地砖上挪，五分钟才换一次。人换房间，她慢慢跟过去。另外每三分钟原地换姿势，站或抱膝坐。擦拭护项圈，底栏：「小委屈：项圈……不摘喵」，贴纸未出，不切特写。

趴和睡要分开，不要都用饿趴那两张。

- 太饿：现在这套，趴地上闭眼，偶尔看你一眼。
- 健康太低：另做躺着或侧躺，脸发红或发青。
- 睡觉：换成睡在纸箱里的静帧。不要另放猫窝物件。拖的时候还是这张，不换动画。

**贴纸。** 站、走（左右脚交替，摆臂放慢，人在画面上仍挪得很慢）、抱膝坐、作揖晃手（两帧）、坐着抱碗吃。站和抱膝坐另加摆尾两帧。待机呼吸约 5.6 秒一圈：只拉长压扁，不上下浮动。站着、坐下同一套。跟人换房间：门口出现，跑向画面中间；奔跑按 Q 版侧面分解，双手前伸定住，只动脚和身子起伏，到位停下大喘气。饥饿低于 20 趴地上：闭眼、偶尔睁眼看你一眼、微弱起伏。日常全靠贴纸在坐标上换。不要为每一次喂、摸出一张 9:16。箱里坐以后再拆。摔趴、头重墩回去留给别的迷你猫娘，她先不用。待机不要用描出发型的投影，影子放脚底，不然头发会像残影。

分解帧对不齐、头发容易残影时，不要硬拆循环。出一张有动感的静帧，网页里平移（拖她就是按住平移）。走、跑已经有循环的先继续用。新的擦拭、拖动、逗一逗、睡觉、求情、难过离去，默认先静帧。

**贴纸画布。** 站、走、跑、坐、喘气、作揖统一 `864×1152`，透明底，脚离底约 12px。网页按宽度铺图，画布一窄人就会被撑大。新图先套这张画布，头宽跟 `stand.png` 接近，再跑 `web/check_stickers.py`。已经裁窄的图可先 `python web/check_stickers.py --normalize` 垫进去。吃和趴另算。找 Gemini、豆包拆帧时读 [贴纸动画提示词](../.cursor/skills/mini-catgirl-anim-prompt/SKILL.md)，不要走 Cursor 出图。

## 以后才做

厕所区域做出来之后：把她抓进去洗澡、涂泡泡。这是清洁的第二套，不是现在这颗「擦拭」。先不要出图。

靠近茶几只换一句（屋檐、遥控器门板那种），不代表打工，不扣体力不赚金币。网页落点 `sofa` 在沙发侧，不是茶几底下；茶几是地毯上那张矮桌，`table` 那块只用来不让她走到桌面上。

窝不用单独强调。睡觉就是纸箱静帧。

玩具是房间物件：地上一张图，谁占用、玩多久。不是新一章分镜。逗一逗的享受贴纸可以先做，玩具物件后做。

房间要先锁空景，再让她进去。开放更多房间之后：加「关禁闭」，把她锁在某一间，人不在她也出不来，取消跟着你换房间。晚上没开灯会有影响，冬天丢阳台掉很多健康，数字都后面再定。现在客厅加阳台不够用，先不要做，也不另出图。外出（街、市场、乡下）也是场地表，路人不用专属分镜；点名带回家的才切静帧，结局写成 flags。

再进门的迷你猫娘是住客，档里最多二十只，会分散在各间，同屋才深度互动。每人五张贴纸加短档案（会不会偷吃、爱钻哪、怎么叫用户）。粮食是屋子的，碗只有一个。第一次偷吃可以切静帧，第五次只记底栏和小事。不要做成收藏 200 只、换住客、收藏值。现在测试仍只放小委屈。

## 先做哪一块

房子页在 `web/`。双击 `打开日常.bat`，或浏览器打开 `web/index.html`。存档、客厅点喂摸、切到阳台、她自己走去阳台、碗会把她叫回来，已经先做。第一章从现有 `options.json` 接进同一张网页，还没接。新分镜先不动。
