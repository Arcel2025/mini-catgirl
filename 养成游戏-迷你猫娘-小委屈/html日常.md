# 小委屈 · HTML 日常

能玩的主循环改成网页小游戏。对照是小红书「纸箱猫」的房间页：固定场地、角色贴纸、点一下换一句。不是图鉴，不是抽卡。

人设见 `小委屈.md`。第一章分镜见 `小委屈故事.md`。生命数字见 `life/tables.py`，抄进网页时数字不要另编一套。

Python 窗口（`app.py`）仍能播第一章，新日常不要往那扇窗上加。朋友玩的是网页。

## 两层

**日常。** 打开之后一直停着的那一页。房子是主循环：客厅、阳台、以后的房间，各一张空景底图。你进哪间，只渲染那间在场的贴纸。饭盆可拖、点一下倒粮。底下换一行字。顶上走饥饿、清洁、心情、健康。沙发和桌子画在底图里，不当热区。

**事件。** 第一次偷吃、起名、项圈这些，才切现在的 9:16 静帧。播完回到房间。日常点一次喂，只换贴纸和底栏，不黑屏、不换海报。

## 壳

普通网页。HTML 铺房间，JavaScript 算生命核、坐标、存档。不需要 React，不需要游戏引擎，不租云服务器。

给朋友：静态托管（GitHub Pages 一类）发链接。小红书小工具以后是同一套离线页，只是打包方式不同。存档在对方浏览器里。

本机开发：文件夹打开即可。图继续用 `packs/xiaoweiqu/assets/`。剧情继续吃 `packs/xiaoweiqu/options.json`。

## 存档

浏览器 `localStorage`。JSON 字段沿用现在的 `Save`：`vitals`、`gold`、`flags`、`life_phase`、`last_simulated_at`、`rng_state`，网页另加 `inventory`（背包）。打开页先按上次时间把离开的那段补上，跟现在窗口同一套核。

房子另加 `house`：

- 你在看哪一间（`view`）
- 住客表：每只在哪间、哪个落点、贴纸、坐标（测试只有小委屈）
- 碗里还有多少粮（0–10）
- 饭盆在哪一间、坐标
- 底下那行字

档里最多二十只。场上只画当前房间里的人。旧档只有 `room` 的，读进来当成她在客厅。

页面只看当前这一档。齿轮弹窗里是金币、时间、背包；仍可导出、导入 JSON。换手机、清缓存、无痕模式会丢档，导出是备份。不要云存档。旧的二三档键如果还在浏览器里，页面不再提供切换。

## 日常页

第一章字卡「第一章结束」之后进这一页。进房间时打开 `daily_life`。不等第二章写完。

**看见的。** 先测两间：横版俯视空客厅 `living.png`；横版空阳台 `web/assets/balcony.png`（按平面图晒衣阳台新出，不是第一章竖图拉长）。第一章 `ch1-balcony.png` 仍是 9:16 剧情图。房子怎么连看 `packs/xiaoweiqu/assets/house-floorplan.png`。画面贴左边。能去的地方在画面顶上那条黑边。右侧固定管理栏：小地图只看（红点是她，蓝标是你，不点开）、顶上黑条最右边齿轮打开当前存档（金币、时间、可折叠背包；导出导入）、小委屈卡片标题行写名字和位置，折叠也能看见她在哪；点开才是饥饿清洁心情健康体力、擦拭吃药复活。五项条：80–100 红，40–80 绿，10–40 浅绿，0–10 灰。底栏只留一句。她开口一律「名字：台词」，例如「小委屈：人人……饿饿……」。金币不够、那边有吃饭的声音这类系统句不带名字。她是站姿贴纸 `stand.png`。客厅里远小于沙发和餐桌；阳台上同一贴纸大小，不近大远小。不锈钢饭盆可拖到地上任意位置，吃饭贴纸和站姿一样大。沙发、茶几、餐桌只画在底图上，不当贴图、不点。第一版不要「去茶几底下钻」。房间空景还没锁，顶上先只放能去的地方。

**点的。**

- 点她：摸摸。心情加一点。只换底栏。数字 `PET_MOOD` 写在 `web/life.js`，表里没有这一项。人不在这间就摸不到。
- 点「坐下」：叫她原地抱膝坐。点「站起来」：叫她站回去。已经是那个姿势、在吃、在跑、在作揖求饭时不听。
- 点饭盆：倒粮动画，存量加满到 10。拖开饭盆，放哪间算哪间，换房间不会把盆带走。饥饿降到 40 且盆里有粮：饭在这间就自己走到盆边。饭在另一间，她不敢离开你，站在原地作揖晃手（换帧），底栏：「小委屈：人人……饿饿……」，一直求到你带她去、或把盆拿到这间。1 点/一只/一次。
- 拖她：走着、跑着也能拖开。按下就停步，松手停在放下的位置，不吸到地毯 / 碗边 / 窗边那些格子。桌子还是先不让当落点。不是满屋物理。
- 切房间：画面顶上客厅 / 阳台。阳台门口也能点回客厅。人去哪间，她就慢慢跟去哪间（跟着鞋）。每跟一次扣体力 10、饥饿 10、清洁 10。进门从门口跑；客厅跑到地毯上，阳台跑向画面正中。出汗脸红狂奔，到位大喘气。腿短，走得大约是原来的十分之一。
- 存档：顶上黑条最右边齿轮，地图左边。弹窗里看当前档的金币、时间、背包（点开才列出内容，没有就显示空），仍可导出导入。不再切一二三。

你不点，时间也走。她自己换位时不离开你所在的那一间：客厅只在地毯上挪，阳台只在地砖上挪，五分钟才换一次。人换房间，她慢慢跟过去。另外每三分钟原地换姿势，站或抱膝坐。擦拭仍护项圈，底栏：「小委屈：项圈……不摘喵」，不为此切特写。

**贴纸。** 站、走（左右脚交替，摆臂放慢，人在画面上仍挪得很慢）、抱膝坐、作揖晃手（两帧）、坐着抱碗吃。站和抱膝坐另加摆尾两帧。待机呼吸约 2.8 秒一圈：重心轻轻上下、身形微微拉长压扁。跟人换房间：门口出现，跑向画面中间；奔跑按 Q 版侧面分解，双手前伸定住，只动脚和身子起伏，到位停下大喘气。饥饿低于 20 趴地上：闭眼、偶尔睁眼看你一眼、微弱起伏。日常全靠这几张在坐标上换。不要为每一次喂、摸出一张 9:16。箱里坐、摔趴以后再拆。待机不要用描出发型的投影，影子放脚底，不然头发会像残影。

**已知、先不改。** 拖她换走路贴纸时，人比站着大一圈。走路图画布比站姿窄（770×1124 对 864×1152），同一 CSS 宽度下人显得更大。明天按头对齐。

## 以后才做

玩具是房间物件：地上一张图，谁占用、玩多久。不是新一章分镜。

房间要先锁空景，再让她进去。外出（街、市场、乡下）也是场地表，路人不用专属分镜；点名带回家的才切静帧，结局写成 flags。

再进门的迷你猫娘是住客，档里最多二十只，会分散在各间，同屋才深度互动。每人五张贴纸加短档案（会不会偷吃、爱钻哪）。粮食是屋子的，碗只有一个。第一次偷吃可以切静帧，第五次只记底栏和小事。不要做成收藏 200 只、换住客、收藏值。现在测试仍只放小委屈。

## 不做

- 把 tkinter 窗口当房间舞台
- 为日常每一动切整张立绘或黑屏过场
- 网页前端再挂一台 Python 云服务器
- 纸箱猫的开箱、图鉴、换住客

## 先做哪一块

房子页在 `web/`。双击 `打开日常.bat`，或浏览器打开 `web/index.html`。存档、客厅点喂摸、切到阳台、她自己走去阳台、碗会把她叫回来，已经先做。第一章从现有 `options.json` 接进同一张网页，还没接。新分镜先不动。
